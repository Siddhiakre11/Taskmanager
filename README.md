# Task Manager

Task Manager is a full-stack web application designed to help users efficiently create, organize, update, and track their daily tasks. The application is built using React.js for the frontend, providing a responsive and interactive user experience, while Spring Boot and Java power the backend through RESTful APIs that handle business logic and data processing. MySQL is used as the database to ensure reliable and persistent storage of task information.

The project demonstrates the integration of modern frontend and backend technologies, including React component-based architecture, Spring Boot REST API development, database connectivity using Spring Data JPA, and full CRUD (Create, Read, Update, Delete) operations. The application enables seamless communication between the frontend and backend, offering a complete end-to-end task management solution.

## Technologies Used

* React.js
* Java
* Spring Boot
* Spring Data JPA
* MySQL
* RESTful APIs
* Maven
* HTML5
* CSS3
* JavaScript
